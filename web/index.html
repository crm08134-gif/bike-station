기존 대여소 비교

지도 표시

  • 선택한 대여소 (혜택 구간의 끝으로 쓰임)
  • 선택했지만 끝으로 쓰이지 않은 대여소
  • 기존 따릉이 대여소 (누르면 이름·번호)
  • 혜택 받는 통행 (대여소 사이를 탈 수 있음)
  • 혜택 없는 통행
  • 누른 대여소의 도보 반경 안 통행
